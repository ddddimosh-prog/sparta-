How to preview:
1. Extract the ZIP.
2. Open index.html in a browser.
3. Use the navigation to visit Price List and Trainers.

Before publishing:
- Replace the sample brand colors after checking the real Instagram feed.
- Replace CSS gradient photo placeholders with approved gym photos.
- Add verified prices, trainer details, opening hours, address and phone.
- Replace the generic WhatsApp links with the gym's actual WhatsApp number:
  https://wa.me/COUNTRYCODEPHONENUMBER
- Confirm every listed service and achievement with the gym.

This is a static front-end prototype. It does not include a booking system,
admin panel, database, or online payments.
